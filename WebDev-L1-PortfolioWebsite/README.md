# Task 2 – Personal Portfolio Website

## Project Description
This project is a personal portfolio website developed as part of my Oasis Infobyte Web Development & Designing Internship (Level 1).

The website showcases my personal profile, technical skills, projects, and contact information through a simple and user-friendly design.

## Technologies Used
- HTML5
- CSS3

## Features
- Home section
- About Me section
- Skills section
- Projects section
- Contact section
- Navigation menu
- Responsive layout

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `screenshots/` – Project screenshots

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
